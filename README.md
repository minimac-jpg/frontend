# Maple Web UI

React/TypeScript frontend for the Maple CI/CD platform.

## Development

```bash
npm install
AUTH_MODE=dev cargo run --bin controller # run in main directory or run !1024
npm run dev # run in /apps/web-ui
```

## Build

```bash
npm run build
npm run preview
```

## Tech Stack

- React 19
- TypeScript 5.8
- Vite 6
- TanStack Router
- TanStack Query
- Tailwind / Shadcn/ui
